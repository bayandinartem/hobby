# Королевство

Локальная настольная игра в средневековом сеттинге. Приложение написано на чистом JavaScript с ES-модулями и DOM, без сторонних игровых библиотек и Canvas.

## Запуск

ES-модули в браузере нужно открывать через HTTP(S), а не через `file://`. Из корня проекта запустите любой локальный статический сервер, например:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Также можно открыть корневой каталог в VS Code и воспользоваться расширением Live Server.

## Поддерживаемые экраны

Интерфейс адаптируется для современных настольных браузеров, планшетов и телефонов от 320 px шириной. На узком экране игровое поле остаётся квадратным, а панели хода и игроков располагаются под ним. На телефоне клетки владений показывают группу и крупную цену; нажатие открывает подробную карточку с рентой и действиями. Игра рассчитана на передачу одного устройства между 2–4 игроками.

## План реализации

1. Зафиксировать адаптацию для настольных браузеров, планшетов и телефонов; поддерживать узкие экраны от 320 px, не требовать hover и сохранять основные действия доступными касанием и клавиатурой.
2. Описать 40 клеток, средневековые группы владений, стоимость, ренту и карточные события как данные.
3. Реализовать независимую от DOM модель партии: ходы, кубики, перемещение, стартовый бонус, покупки, ренту, подать, карты, подземелье, улучшения, залог и банкротство.
4. Добавить DOM-отрисовку поля, фишек, владений, состояния хода, панели игроков и летописи; загружать модули через `main.js`.
5. Сверстать адаптивное поле и панели: широкий экран — поле и боковая панель рядом, телефон — поле сверху и действия ниже; элементы управления не должны зависеть от наведения мыши.
6. Проверить запуск через HTTP(S), прохождение основных сценариев партии, отсутствие ошибок модулей и горизонтальной прокрутки на телефонном экране.
7. После MVP отдельно рассмотреть аукционы, сохранение партии, обмен между игроками, звук/анимации и компьютерного соперника.

## Структура

- `index.html` — точка входа.
- `main.js` — создание партии и обработчики интерфейса.
- `js/data.js` — поле, группы владений и карточки.
- `js/game.js` — состояние партии и правила.
- `js/ui.js` — отображение состояния в DOM.
- `styles.css` — оформление и адаптивные раскладки.
