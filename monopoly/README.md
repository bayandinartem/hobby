# Королевство

Локальная настольная игра в средневековом сеттинге. Приложение написано на чистом JavaScript с ES-модулями и DOM, без сторонних игровых библиотек и Canvas.

## Запуск

ES-модули в браузере нужно открывать через HTTP(S), а не через `file://`. Из корня проекта запустите любой локальный статический сервер, например:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Также можно открыть корневой каталог в VS Code и воспользоваться расширением Live Server.

## Автотесты

Требуется Node.js 16 или новее. В папке проекта запустите:

```sh
npm test
```

Тесты не требуют установки сторонних пакетов. Они проверяют переходы правил, экономику, тюрьму, карты, владения и сделки, звуковые эффекты, полные детерминированные партии на русском и английском, покрытие переводами поля и карточек, рендеринг и вычисление/запуск анимации фишек.

## Поддерживаемые экраны

Интерфейс адаптируется для современных настольных браузеров, планшетов и телефонов от 320 px шириной. На узком экране игровое поле остаётся квадратным, а панели хода и игроков располагаются под ним. Фишки игроков выполнены силуэтами человечков и анимированно перемещаются по клеткам после броска. На телефоне клетки владений показывают группу и крупную цену; нажатие открывает подробную карточку с рентой и действиями. Игра рассчитана на передачу одного устройства между 2–4 игроками.

## Звуки

Звуковые эффекты синтезируются встроенным Web Audio API без аудиофайлов и сторонних библиотек: звук броска кубиков, шаги при перемещении и звон монет при покупке, продаже и улучшении владений. Звук можно выключить или включить кнопкой на стартовом экране и во время партии.

## Языки

Русский выбран по умолчанию; English можно выбрать на стартовом экране. Язык партии фиксируется при её запуске и применяется к правилам, карточкам, игровому полю, панели владений и итоговому экрану. Проверка обязательных имён выполнена внутри приложения и показывает сообщение на выбранном языке, не используя браузерный системный tooltip.

Чтобы добавить язык, добавьте его код в `supportedLocales` и заполните соответствующие записи `translations`, `tileNames` и `cards` в `js/i18n.js`. Клетки поля и карточки используют стабильные `translationKey`/`textKey` из `js/data.js`, поэтому перевод не зависит от порядка элементов доски или колоды. Игровая логика и раскладка поля при этом не меняются.

## Сделки между игроками

В карточке своего незаложенного владения игрок может в любой момент предложить его другому игроку за указанную цену. Также игрок может предложить владельцу чужого незаложенного владения выкупить его и указать цену. Получатель каждого предложения принимает или отклоняет его; при принятии деньги переводятся между игроками, а владение вместе с построенными домами или замком переходит покупателю. Заложенное владение нельзя выставить на продажу или предложить к выкупу. Пока ждут ответа на предложение, остальные игровые действия приостановлены.

## План реализации

1. Зафиксировать адаптацию для настольных браузеров, планшетов и телефонов; поддерживать узкие экраны от 320 px, не требовать hover и сохранять основные действия доступными касанием и клавиатурой.
2. Описать 40 клеток, средневековые группы владений, стоимость, ренту и карточные события как данные.
3. Реализовать независимую от DOM модель партии: ходы, кубики, перемещение, стартовый бонус, покупки, ренту, подать, карты, подземелье, улучшения, залог, сделки и банкротство.
4. Добавить DOM-отрисовку поля, фишек, владений, состояния хода, панели игроков и летописи; загружать модули через `main.js`.
5. Сверстать адаптивное поле и панели: широкий экран — поле и боковая панель рядом, телефон — поле сверху и действия ниже; элементы управления не должны зависеть от наведения мыши.
6. Проверить запуск через HTTP(S), прохождение основных сценариев партии, отсутствие ошибок модулей и горизонтальной прокрутки на телефонном экране.
7. После MVP отдельно рассмотреть аукционы, сохранение партии, звук/анимации и компьютерного соперника.

## Структура

- `index.html` — точка входа.
- `main.js` — создание партии и обработчики интерфейса.
- `js/data.js` — поле, группы владений и карточки с ключами переводов.
- `js/i18n.js` — языковые каталоги, форматирование и локализованные игровые строки.
- `js/game.js` — состояние партии и правила.
- `js/movement.js` — маршрут и Web Animations API для перемещения фишек.
- `js/ui.js` — отображение состояния в DOM.
- `styles.css` — оформление и адаптивные раскладки.
- `tests/run.js` — dependency-free регрессионные тесты игрового движка и UI.
